# BoardHub 隐私政策（GitHub Pages）

本仓库用于托管《棋乐无穷 BoardHub》的隐私政策，供 TapTap 国际版商店页填写隐私政策 URL。

- 页面文件：index.html（中英双语）
- 版本：v1.2.0 · 生效日期 2026-10-20
- 适用平台：TapTap 国际版（Android）
- 开发者：BoardHubGames
- 客服邮箱：boardhub.games1@gmail.com

## 发布方式

1. 本仓库必须为 **Public**（免费账号的 GitHub Pages 不支持私有仓库）。
2. Settings → Pages → Build and deployment
   - Source: Deploy from a branch
   - Branch: `main`，目录 `/ (root)`
   - Save
3. 等待 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

## 更新

直接替换根目录的 index.html 并提交，Pages 会自动重新构建，URL 不变。

> 本页为单文件、内联样式，无外部依赖；无需构建命令。
